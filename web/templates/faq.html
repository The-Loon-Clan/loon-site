Frequently asked

What is this?

A reference host for loon, an indexer framework. It exists to prove the framework's seams work end to end, so it runs the same plugin code a production site would.

Why does it look like a tracker but talk about Usenet?

The design system is ported from UNIT3D, a BitTorrent tracker. The data underneath is a Usenet index. Anything that only makes sense for a tracker — ratio, seeding, peers, upload credit — is absent rather than faked, so some familiar chrome is deliberately missing.

Where do releases come from?

An admin points the crawler at an NNTP provider and enables a few newsgroups; the usenet plugin assembles headers into releases. See the groups page for what is being crawled.

Is there an API?

Yes — a Newznab-compatible endpoint. Generate a key on your API key page.

What are points for?

They are the framework's ledger seam, earned from the daily reward and spent in the store. They buy nothing of consequence here; the point is that the plumbing is real.
