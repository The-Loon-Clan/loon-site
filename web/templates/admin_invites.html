How invites work here

0 means no limit. The cap counts only invites that can still be claimed — an expired one does not hold a member back.

  • Off means members mint a bare code and pass it on themselves. The chain still records who issued it.
  • Off treats the address as where it was sent rather than who may redeem it — a forwarded invite then still works.
  • Off records the invite and sends nothing, leaving the member to pass the code on. Useful on a site with no mail configured.
  • Staff can always withdraw one from the chain below, whatever this says.
  • Off means an invite spent is spent. On is the fairer default and cannot be farmed — the refund only happens on a withdraw that actually cancelled something.
  • How many members somebody brought in, on their public profile. Off by default: it is a social graph, and publishing one should be a decision.
