About this site

This is the loon indexer: the smallest useful HOST for the loon framework. Every capability a real site would implement — sessions, users, points, notifications, entitlements, storage — is wired here against a real Postgres, and every feature you can click is a plugin from loon-plugins running the same code a production deployment would run.

What is running

  • usenet — NNTP crawling and release assembly
  • catalog + scraper — Newznab taxonomy and cover-art matching
  • forum, news, wiki, messages, tickets — the community surfaces
  • pointstore, store, ranks, rewards, dailyreward — the points economy
  • stats, backups — operational plumbing

The design

The interface is a port of UNIT3D's design system — its class vocabulary, its panel and table components, and its CSS-custom-property theming. It ships three themes; pick one from the Theme menu in the header.

Honesty

A demo is tempting to dress up. This one does not: figures come from real reads or the panel is dropped, and the handful of pages built ahead of their data are marked MOCK in the interface and listed in the repository's mock register.
