# Code of Conduct

## The short version

Be decent to people. Assume the person you are replying to is acting in good
faith and knows things you do not.

## The longer version

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. It is used by tens of thousands of projects, so it is probably
already familiar, and being the same document everywhere is most of its value.

In short: harassment, personal attacks, and unwelcome attention are not
tolerated, in the issue tracker or anywhere else the project is discussed.
Technical disagreement is not any of those things — arguing hard about a design
while treating the other person as a colleague is exactly what this is for.

## Reporting

Report a problem privately via a
[GitHub security advisory](https://github.com/The-Loon-Clan/loon-site/security/advisories/new)
or by contacting the maintainers directly. Reports are handled discreetly.

This is a small project. There is no committee — a maintainer will read your
report and act on it, and will tell you what they did.
